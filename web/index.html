ЗАПУСК MINI

Модель из вкладки «Новый прогон»—
Оценка расхода≈ —
Это расчёт по входным текстам и резерву ответов, а не обещание списания. Фактические токены видны во время прогона.
Для reasoning-моделей рекомендуем Max tokens 16000+. Настройка находится на вкладке «Новый прогон» → «Дополнительно».
Мини-версии нужны для быстрого сравнения на своём устройстве. Их баллы нельзя напрямую сравнивать с официальными полными leaderboard. HLE проверяется строгой нормализацией ответа без LLM-судьи.
