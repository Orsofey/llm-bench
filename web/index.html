Подключение

Адрес API из документации или кабинета сервиса, который выдал ключ. Протокол (OpenAI или Anthropic) и способ авторизации подберутся автоматически.
Ищу Ollama, LM Studio, llama.cpp, vLLM, Jan, text-generation-webui, KoboldCpp, GPT4All и др. на стандартных портах. Свой порт — укажите в Base URL выше.
Запросы идут через официальный CLI на вашем компьютере, под вашим входом. Расходуется лимит подписки.
С ней сравнивается отпечаток. Пусто — берётся название модели.

Публичные бенчмарки (мини-версии)

Бесплатно: зарегистрируйтесь на huggingface.co, примите условия наборов GPQA и HLE, создайте токен (Settings → Access Tokens, тип Read).
Вопросы одинаковые для всех ключей — результаты можно сравнивать. Баллы не равны официальным: модель отвечает без инструментов.

Ключи для проверки

Одна строка — один ключ. Через «;» или «|» можно добавить: продавца, цену в ₽, объём токенов (1 млн, 500к). Адрес API — в начале строки или в общем поле ниже. Ключи не сохраняются — в отчёте только маска вида sk-ant-…a1b2.

Глубина проверки
