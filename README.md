# LLM Bench · by Orsofey

Приложение для проверки **качества, скорости и подлинности LLM** на практических задачах: кодинг, сложная логика, монтаж, голосовой агент, воронка, следование инструкциям и длинный контекст.

## Готовые приложения

Файлы находятся в [`dist/`](dist/):

- **`LLM Bench.exe`** — portable-приложение для Windows 10/11 x64. Запустите двойным кликом; Python и Node.js устанавливать не нужно. Окно использует встроенный в Windows Edge WebView2.
- **`LLM-Bench-Android.apk`** — самостоятельное приложение для Android 7.0+ на **arm64-v8a и x86_64**. Разрешите установку из выбранного источника, если Android спросит. Компьютер и внешний сервер Orsofey не нужны.

Это локальные, не опубликованные сборки. APK подписан тестовым debug-ключом; для публикации в Google Play нужен собственный release-ключ и AAB. EXE не имеет коммерческой цифровой подписи, поэтому Windows SmartScreen может запросить подтверждение.

## Подключение

**API-ключ** — Anthropic, OpenAI, OpenRouter, DeepSeek, Gemini или **«Другой сервис»**. Интерфейс узнаёт распространённые ключи по префиксу. Для неизвестного ключа укажите адрес API: программа подберёт протокол (OpenAI- или Anthropic-совместимый), авторизацию (`Bearer` или `x-api-key`) и путь (с `/v1` или без).

**Подписка (только Windows)** — через официальные CLI под вашим входом:

| Подписка | Установка | Вход |
|---|---|---|
| Claude Pro/Max | `npm i -g @anthropic-ai/claude-code` | `claude` → `/login` |
| ChatGPT Plus/Pro | `npm i -g @openai/codex` | `codex login` |

Запросы идут через CLI на компьютере и расходуют лимит подписки. На Android доступны API-ключи; CLI-подписки отключены.

### Проверка подлинности

Кнопка **«Только проверить подлинность»** (около 35 запросов) сочетает отпечаток токенизатора, распределение поведения, учёт токенов и служебные признаки API. Один сигнал не считается доказательством.

1. Прогоните официальный ключ с галочкой **«Сохранить как эталон»**.
2. Прогоните ключ другого сервиса.
3. Откройте **«История и сравнение»**.

Разный отпечаток у одной модели — сильный сигнал другой модели; заметно ниже баллы или провал контекста — возможная подмена или обрезка. Эталоны GPT появляются автоматически, если установлен `tiktoken` (в готовый EXE/APK он не включён).

> Бенчмарк выполняет много платных запросов к выбранному API. Перед полным прогоном проверьте баланс и тариф провайдера. Данные истории не содержат API-ключ.

## Локальные данные

- EXE: `%LOCALAPPDATA%\Orsofey\LLM Bench\results\` и профиль WebView.
- Запуск из исходников: `results/` в папке проекта.
- APK: внутреннее хранилище приложения.

Ключи не сохраняются по умолчанию. Если включить **«Запомнить ключ»**, он сохраняется в локальном хранилище WebView на этом устройстве; это не аппаратное шифрование. Не включайте опцию на чужом устройстве.

## Запуск из исходников

Нужен Python 3.10+; зависимостей для движка нет. ffmpeg — по желанию для реального рендера.

- Windows: `start.bat`.
- macOS / Linux: `python3 app.py`.

Откроется `http://127.0.0.1:8787`. Сервер слушает только localhost; ключи отправляются только выбранному API.

## Повторная сборка

### Windows EXE

```powershell
.\build_windows.ps1
```

Скрипт создаёт локальную `.venv`, ставит build-зависимости, генерирует иконку и собирает один EXE через PyInstaller + pywebview.

### Android APK

Нужны JDK 17+, Android SDK, platform `android-36.1` и Python 3.12 для Chaquopy.

```powershell
.\build_android.ps1
```

Скрипт явно передаёт Gradle путь к Python, чтобы избежать ошибок системного launcher. Gradle синхронизирует общие `app.py`, `bench.py`, `verify.py`, `android_bridge.py` и `web/` в APK.

## Тесты и проверка

```powershell
python -m unittest discover -s tests -v
node tools\inspect_ui.mjs 390 844 build\preview-mobile.png
```

Для `inspect_ui.mjs` нужен запущенный `app.py` и Google Chrome. Скрипт проверяет viewport, горизонтальный overflow и делает screenshot.

Smoke-тест собранного EXE:

```powershell
Start-Process ".\dist\LLM Bench.exe" -ArgumentList '--smoke-test', '"полный\путь\smoke.json"' -Wait
```
