# LLM Bench

Локальный бенчмарк, который проверяет **ключ / провайдера** и **качество модели** на ваших задачах: кодинг, монтаж, голосовой агент, воронка, инструкции, длинный контекст.

## Запуск

Нужен Python 3.10+. Других зависимостей нет. ffmpeg — по желанию: с ним команды монтажа реально рендерятся и проверяются через ffprobe.

- Windows: дважды кликнуть `start.bat`
- macOS / Linux:

```bash
python3 app.py
```

Откроется `http://127.0.0.1:8787`. Сервер слушает только localhost, ключи никуда не уходят, кроме API выбранного провайдера.

## Подключение

**API-ключ** — Anthropic, OpenAI, OpenRouter, DeepSeek, Gemini или **«Другой сервис»** для ключей перепродавцов и прокси (`kl_live_…` и любые другие форматы). Интерфейс узнаёт ключ по префиксу и сам выбирает сервис. Для неизвестного ключа укажите адрес API того, кто его выдал. Бенчмарк сам подберёт протокол (OpenAI- или Anthropic-совместимый), авторизацию (`Bearer` или `x-api-key`) и путь (с `/v1` или без). Ошибки объясняются по-человечески: неверный ключ, блокировка региона, нет баланса, неверный адрес.

**Подписка** — через официальные CLI, под вашим входом:

| Подписка | Установка | Вход |
|---|---|---|
| Claude Pro/Max | `npm i -g @anthropic-ai/claude-code` | `claude` → `/login` |
| ChatGPT Plus/Pro | `npm i -g @openai/codex` | `codex login` |

Сторонние сайты не могут легально подключаться к подписке напрямую, поэтому запросы идут через эти CLI на вашем компьютере. Расходуется лимит подписки.

## Проверка подлинности ключа

Кнопка «Только проверить подлинность» (около 35 запросов) отвечает на вопрос, та ли модель стоит за ключом, что заявлена:

| Сигнал | Что показывает |
|---|---|
| Отпечаток токенизатора | Разница входных токенов между запросами с 5 пробными текстами (английский, русский, код, числа, эмодзи) и без них. Скрытая инструкция сервиса при вычитании сокращается, остаётся «почерк» семейства моделей |
| Поведение | Распределение коротких ответов при temperature=1 в сравнении с эталоном |
| Учёт токенов | Соблюдает ли сервис max_tokens и не завышает ли выходные токены |
| Скрытая инструкция | Сколько токенов сервис тайно добавляет к каждому запросу — вы за них платите |
| Формат API, самоназвание | Слабые подсказки |

**Эталоны.** Прогоните официальный ключ с галочкой «Это официальный ключ — сохранить как эталон», либо нажмите «Сделать эталоном» в истории. Эталоны GPT появятся автоматически после `pip install tiktoken`.

**Токены.** Во время прогона видно, сколько всего запросов и токенов на вход и на выход ушло, включая проверки. Эти числа можно сверить с расходом в кабинете сервиса.

Какие публичные бенчмарки актуальны и на каких исследованиях построена проверка, описано в [BENCHMARKS.md](BENCHMARKS.md).

## Как поймать подмену модели

1. Прогоните официальный ключ с меткой `official` — это эталон.
2. Прогоните ключ перепродавца.
3. Откройте «История и сравнение».
   - Разный **отпечаток** (число входных токенов на один и тот же текст) у одной модели — почти наверняка другая модель.
   - Заметно ниже баллы или провален длинный контекст — подмена или обрезка.

## Командная строка

```bash
python bench.py --provider anthropic --key sk-ant-... --model claude-opus-5-5 --tag official
```

```bash
python bench.py --provider claude-cli --model opus
```

```bash
python bench.py --compare results/*.json
```

## Тесты

| Категория | Что проверяется |
|---|---|
| Кодинг | 6 задач, код запускается на скрытых тестах |
| Сложные | калькулятор, wildcard с тестом скорости, парсер SRT, логическая задача, счёт букв, умножение, даты, простые числа, ровно 13 слов |
| Монтаж | ffmpeg (вертикаль 9:16, субтитры + −14 LUFS), отбор дублей, сборка SRT, пересчёт таймкодов |
| Агент (голос) | речь → JSON вызовов инструментов; опасные команды только с подтверждением |
| Воронка | CTR/CR/CPA/ROMI, аномалии, ответы без выдумок |
| Инструкции | формат на русском, строгий JSON |
| Длинный контекст | поиск факта в ~80 тыс. символов |

Задачи лежат в `bench.py` (`TASKS`). Новая задача = промпт + функция проверки, возвращающая `(балл 0..1, комментарий)`.
